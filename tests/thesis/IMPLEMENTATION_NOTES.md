## Decisions documented inline

- **Manifest size:** generated 513 entries (target was ≥ 100). Many
  duplicate the same value across origins (e.g. `factor_alphas_ff6_alpha`
  from PRODUCTION_METRICS and `macro_factoralphasff6alpha` from
  canonical_macros.tex). Cross-deduplication isn't lossless because
  the macro form sometimes uses 2-decimal rounding while the JSON
  carries 6+ decimals. Both are kept.
- **Methodology audits:** kept narrow per spec §6 (one class per
  script, plus a cross-cutting parametrized check). Did not extend
  to the do-not-audit list (cross_sectional_model, expanding_window_*,
  xgb_cv, hmm_cv, leg_betas_by_regime, apply_shumway_*,
  cross_sectional_intl, hmm_intl, import_intl_stocks, fundamentals_test,
  random_forest_test).
- **Coverage gate strict mode:** controlled by `THESIS_GATE=strict`
  env var. Default warn-mode passes always.
- **Tolerances:** generated defaults per leaf type (t-stats: ±0.05,
  alphas-in-percent: ±0.1, raw ratios: section-dependent). Tightening
  these is a separate exercise.
