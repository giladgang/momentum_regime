# Thesis Verification Suite

Single-command verification that the thesis is internally and methodologically
sound. Layered design — each layer is independent and can be run on its own.

```bash
pytest tests/thesis/                                     # everything
pytest tests/thesis/test_numbers.py -v                   # Layer 1: manifest checks
pytest tests/thesis/test_methodology.py -v               # Layer 2: source audits
pytest tests/thesis/test_coverage_gate.py -v             # Layer 3: coverage report
pytest tests/thesis/test_e2e_smoke.py -v                 # Layer 4: pipeline smoke
pytest tests/thesis/test_hygiene.py -v                   # Layer 5: plumbing
```

## Layout

```
tests/thesis/
  manifest.yaml                # source of truth for thesis claims (auto-generated)
  manifest_generation_report.md  # what's covered, what needs followup
  make_manifest.py             # regenerate manifest from _expected/PRODUCTION_METRICS/canonical_macros
  conftest.py                  # session fixtures + helpers
  test_numbers.py              # Layer 1 — parametrized manifest checks
  test_methodology.py          # Layer 2 — static source audits (6 scripts)
  test_coverage_gate.py        # Layer 3 — coverage_report.md generator
  test_e2e_smoke.py            # Layer 4 — runs run_pipeline.py --repro-smoke
  test_hygiene.py              # Layer 5 — pickle staleness, RNG, plot/CSV parity
  make_smoke_fixture.py        # local-only: generate fixtures/smoke_*
  fixtures/
    .gitkeep
    PROVENANCE.md              # template; overwritten by make_smoke_fixture.py
  coverage_whitelist.txt       # decimals classified as config, not result
  rng_hygiene_whitelist.txt    # scripts allowed to seed at module level
  coverage_report.md           # gitignored; generated by Layer 3
```

## Layer 1 — `test_numbers.py`

Parametrized over `manifest.yaml`. Each entry runs three sub-checks:

  1. **CSV/TEX row check** — load `source.csv` (or .tex), apply `selector`,
     read `column`, compare to `published.value` within `tolerance`.
  2. **Citation check** — verify each `cites[]` locator (regex or
     row=...; col=...) hits in the cited file.
  3. **Canonical-consistency** — when `canonical: EXP.X` is set, assert
     `published.value == getattr(_expected, X)`.

A failure on any sub-check fails the parametrized case (with all three
sub-failures aggregated into the message). Failing cases are SIGNAL —
they show real drift between the thesis prose, the canonical CSVs,
and the pinned constants.

## Layer 2 — `test_methodology.py`

Static-source audits, mirroring `tests/test_cross_sectional_lookahead.py`,
for the six scripts NOT covered by the legacy suite:

  - `scripts/bootstrap_analysis.py`
  - `scripts/zscore_subregime_analysis.py`
  - `scripts/zscore_subregime_xgb_seed_robustness.py`
  - `scripts/historical_oos_posthoc.py`
  - `scripts/seed_convergence.py`
  - `scripts/run_rolling_experiment.py`

Scripts already covered elsewhere are listed at the top of the file
and explicitly NOT re-audited.

## Layer 3 — `test_coverage_gate.py`

Walks every `latex/*.tex` and `main.tex`, extracts decimal tokens, compares
against the union of canonical macros, _expected.py, manifest values, and
the whitelist. Writes `tests/thesis/coverage_report.md` (gitignored).

Default mode: PASSES regardless of orphan count (warn-mode).
Strict mode: `THESIS_GATE=strict pytest tests/thesis/test_coverage_gate.py`
fails if any orphans exist.

## Layer 4 — `test_e2e_smoke.py`

Runs `python run_pipeline.py --repro-smoke` under a tempdir output root and
compares to a committed fixture. **Skipped** unless both fixtures exist:

  - `tests/thesis/fixtures/smoke_baseline.json`
  - `tests/thesis/fixtures/smoke_artefacts.pkl`

Generate them once locally:

```bash
python tests/thesis/make_smoke_fixture.py
```

Target wall time: < 30 minutes on a 6-core box.

> The cloud agent that authored this suite **deliberately does not run**
> `make_smoke_fixture.py`. Fixtures must come from a clean local run pinned
> to `requirements.lock`.

## Layer 5 — `test_hygiene.py`

Plumbing health checks:

  - **Pickle staleness** — `artefacts/cs_artefacts_data.pkl` mtime ≥
    max input parquet mtime
  - **Plot/CSV parity** — each plot script references the canonical
    CSV path
  - **RNG hygiene** — no module-level `np.random.seed` /
    `random.seed` / `torch.manual_seed` in any `scripts/*.py` (whitelist:
    `tests/thesis/rng_hygiene_whitelist.txt`)
  - **dtype invariants** — train artefacts, panel_with_regimes parquet,
    top results CSVs

## Adding a manifest entry

Edit `tests/thesis/manifest.yaml`. Schema (see `make_manifest.py` for
canonical defaults):

```yaml
- id: my_new_claim                  # snake_case, unique
  category: performance              # see schema for valid categories
  description: "Short human-readable description"
  published:
    value: 1.11                      # may be a list for grouped claims
    unit: ratio                      # ratio|percent|tstat|count|months|usd|beta
    tolerance:
      abs: 0.02                      # OR rel: 0.01 OR stars: '***'
  source:
    csv: results/thesis/my_results.csv
    selector: { strategy: "M2 (XGB)" }
    column: sharpe
  cites:
    - { file: latex/main_results.tex, locator: "regex=Sharpe\\s+1\\.11(?!\\d)" }
    - { file: tables/table_performance.tex, locator: "row=M2: XGB; col=3" }
  canonical: EXP.M2_SHARPE_FULL      # optional cross-ref
```

Then re-run the suite:

```bash
pytest tests/thesis/test_numbers.py::test_manifest_entry[my_new_claim] -v
```

To bulk-regenerate the manifest from current sources:

```bash
python tests/thesis/make_manifest.py
```

`make_manifest.py` overwrites `manifest.yaml` and rewrites
`manifest_generation_report.md`. Hand-edits to `manifest.yaml` will
be lost — apply such edits in `make_manifest.py` instead, or maintain
them in a separate companion file.

## Populating fixtures

```bash
# In a clean local checkout, with requirements.lock installed:
python tests/thesis/make_smoke_fixture.py
# Inspect the fixture:
ls -la tests/thesis/fixtures/
cat tests/thesis/fixtures/PROVENANCE.md
# Verify the smoke test passes:
pytest tests/thesis/test_e2e_smoke.py -v
# Then commit:
git add tests/thesis/fixtures/smoke_baseline.json
git add tests/thesis/fixtures/smoke_artefacts.pkl
git add tests/thesis/fixtures/PROVENANCE.md
```

The fixtures are gitignored by default; commit them explicitly only
once provenance is verified.
