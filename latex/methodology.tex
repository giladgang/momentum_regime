\section{Methodology}\label{sec:methodology}

The two-stage empirical framework underlying the analysis is developed as follows. The first stage estimates market regimes using a Bayesian Hidden Markov Model (Section~\ref{sec:stage1}). A two-state HMM is fit to four macrofinancial stress indicators via Gibbs sampling, producing a monthly filtered probability $\pi_t^{\text{filter}}$ that quantifies how likely the market is to be in a panic state. Because this probability is computed using only information available at time $t$, it can serve as a real-time trading signal.

The second stage uses this regime signal to guide cross-sectional stock selection (Section~\ref{sec:stage2}). Three portfolio construction methods (a deterministic formula, logistic regression, and XGBoost) combine $\pi_t^{\text{filter}}$ with momentum and fundamental characteristics to rank stocks each month. The key hypothesis is that the optimal weighting of these characteristics shifts across regimes: long-horizon momentum dominates in calm markets, while short-term reversal and defensive fundamentals become more important during panic periods. By conditioning on $\pi_t^{\text{filter}}$, the models can learn these regime-dependent patterns and adapt portfolio composition accordingly.

\subsection{Stage 1: Regime Classification via Hidden Markov Model}\label{sec:stage1}

\subsubsection{Model Specification}\label{sec:hmm_spec}

This thesis employs a two-state Bayesian Hidden Markov Model to classify the market into latent regimes. The hidden state $s_t \in \{0, 1\}$ represents the unobserved regime at month $t$, where $s_t = 0$ denotes the \emph{calm} regime and $s_t = 1$ denotes the \emph{panic} regime. Crucially, as emphasized by \citet{Hamilton1989}, market regimes are not directly observable: an investor cannot know with certainty whether the market is currently in a calm or panic state. While regime classifications may appear obvious in retrospect -- for example, the 2008 financial crisis is clearly identifiable as a panic period when viewed historically -- distinguishing regimes in real time is fundamentally uncertain. The HMM formalises this uncertainty by treating regimes as hidden states that must be inferred probabilistically from observable market data (see Figure~\ref{fig:hmm_diagram}).

\textbf{Observation equation} Conditional on the regime, the vector of standardized features $\mathbf{z}_t \in \mathbb{R}^D$ (where $D = 4$) is drawn from a regime-specific multivariate Gaussian:
\begin{equation}
    \mathbf{z}_t \mid s_t = 0 \sim \mathcal{N}(\boldsymbol{\mu}_0, \boldsymbol{\Sigma}_0), \qquad \mathbf{z}_t \mid s_t = 1 \sim \mathcal{N}(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1).
\end{equation}
Each regime is characterized by its own mean vector $\boldsymbol{\mu}_k \in \mathbb{R}^D$ and covariance matrix $\boldsymbol{\Sigma}_k \in \mathbb{R}^{D \times D}$, where $k \in \{0\text{ (calm)},\, 1\text{ (panic)}\}$. The multivariate specification allows the model to capture not only level differences in individual features across regimes, but also changes in the correlation structure; for instance, stress features may become more correlated during panic periods.

\bigskip
\textbf{Transition equation} The evolution of the hidden state follows a first-order Markov chain with a $2 \times 2$ transition matrix:
\begin{equation}
    \mathbf{P} = \left(\begin{array}{cc} P_{00} & P_{01} \\ P_{10} & P_{11} \end{array}\right),
\end{equation}
where $P_{ij} = P(s_t = j \mid s_{t-1} = i)$ and each row sums to one. The diagonal elements $P_{00}$ (calm persistence) and $P_{11}$ (panic persistence) govern how likely each regime is to continue into the next month. The expected duration of the calm regime is $1 / (1 - P_{00})$ months, and likewise $1 / (1 - P_{11})$ for the panic regime.

The model inverts this generative process: given only the observed features $\mathbf{z}_{1:t}$, it infers the filtered probability $\pi_t^{\text{filter}} = P(s_t = 1 \mid \mathbf{z}_{1:t})$, a real-time estimate of whether the market is currently in a panic state. \subsubsection{Bayesian Estimation via Gibbs Sampling}\label{sec:gibbs}

Rather than estimating the model by maximum likelihood, this thesis adopts a Bayesian approach and draws from the joint posterior:
\[
p\!\left(\{s_t\}_{t=1}^T,\; \{\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k\}_{k=0}^1,\; \mathbf{P} \,\middle|\, \mathbf{z}_{1:T}\right).
\]
This posterior is not available in closed form because the hidden states and model parameters depend on each other. Gibbs sampling \citep{AlbertChib1993}, a Markov chain Monte Carlo (MCMC) method, resolves this by alternating between three conditional updates: (i) the full hidden state path $\{s_t\}_{t=1}^T$, (ii) the emission parameters $(\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k)$ for each regime, and (iii) the transition matrix $\mathbf{P}$. Because conjugate priors are used, each block can be sampled exactly from its conditional posterior.

\paragraph{Prior Specification.}\label{sec:priors}

The priors encode two economic beliefs. First, before seeing the data, neither regime should be forced to have extreme values in any feature; the model should learn the characteristics of calm and panic states from the data. Second, regimes should be persistent rather than switching every few months.

\paragraph{Emission parameters.}
For each regime $k$, the mean vector and covariance matrix are given a conjugate Normal-Inverse-Wishart prior:
\begin{equation}
\boldsymbol{\Sigma}_k \sim \mathcal{IW}(\nu_0,\boldsymbol{\Psi}_0),
\qquad
\boldsymbol{\mu}_k \mid \boldsymbol{\Sigma}_k
\sim
\mathcal{N}\!\left(\mathbf{m}_0,\frac{\boldsymbol{\Sigma}_k}{\kappa_0}\right).
\end{equation}
The hyperparameters are chosen as
\[
\mathbf{m}_0 = \mathbf{0},\qquad
\kappa_0 = 0.01,\qquad
\nu_0 = D+2,\qquad
\boldsymbol{\Psi}_0 = \mathbf{I}_D(\nu_0-D-1),
\]
where $D=4$ is the number of features. Since all features are standardized, $\mathbf{m}_0=\mathbf{0}$ centers the prior mean at zero, and $\boldsymbol{\Psi}_0$ is calibrated so that
\[
\mathbb{E}[\boldsymbol{\Sigma}_k] = \mathbf{I}_D.
\]
Thus, before seeing the data, each regime is weakly assumed to have unit marginal variance and no cross-feature correlation. The very small value $\kappa_0=0.01$ implies an almost flat prior on the regime mean, so the posterior mean is driven overwhelmingly by the data.

\paragraph{Transition matrix.}
Each row of the transition matrix is assigned an independent Dirichlet prior:
\begin{equation}
\mathbf{P}_{0,\cdot} \sim \text{Dir}(9,1),
\qquad
\mathbf{P}_{1,\cdot} \sim \text{Dir}(1,9).
\end{equation}
Equivalently, in matrix form,
\[
\boldsymbol{\alpha}_{\text{dir}}
=
\left(\begin{array}{cc}
9 & 1 \\
1 & 9
\end{array}\right).
\]
This prior favors persistence in both regimes: absent data, the prior mean transition matrix is
\begin{equation}
\mathbb{E}[\mathbf{P}] =
\left(\begin{array}{cc}
0.90 & 0.10 \\
0.10 & 0.90
\end{array}\right).
\end{equation}
In other words, the prior expects each regime to continue with probability $0.9$, corresponding to an expected duration of roughly $10$ months. This prior is informative enough to discourage pathological solutions, but with hundreds of training observations its influence is dominated by the data.

\paragraph{Gibbs Sampler.}\label{sec:gibbs_sampler}

\paragraph{Initialization.}
The Gibbs sampler requires starting values for the emission parameters and the transition matrix. A crude volatility-based partition is used:\footnote{The choice of initialization has negligible impact on the posterior: the sampler is run for 2{,}000 iterations with 500 discarded as burn-in, and convergence diagnostics (Section~\ref{sec:convergence}) confirm that the chain mixes well regardless of the starting partition.} months with above-median $VOL_t^z$ are initially assigned to the panic state ($s_t=1$), and the remaining months to the calm state ($s_t=0$). The initial emission parameters are then computed from each group:
\[
\boldsymbol{\mu}_k^{(0)} = \frac{1}{n_k}\sum_{t:\,s_t=k}\mathbf{z}_t,
\qquad
\boldsymbol{\Sigma}_k^{(0)} = \text{Cov}(\{\mathbf{z}_t : s_t=k\}),
\]
where $n_k$ is the number of months assigned to regime $k$. The initial transition matrix is set to
\[
\mathbf{P}^{(0)} = \left(\begin{array}{cc} 0.95 & 0.05 \\ 0.10 & 0.90 \end{array}\right).
\]
These initial parameters give the first FFBS forward pass emission densities that can distinguish the two states.

\paragraph{Iterative updates.}
One Gibbs iteration consists of three steps:
\begin{enumerate}
    \item sample a complete state path $\{s_t\}_{t=1}^T$ given the current emission parameters and transition matrix;
    \item sample $(\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k)$ for each regime given the sampled state path, holding $\mathbf{P}$ fixed;
    \item sample $\mathbf{P}$ given the sampled state path, holding the emission parameters fixed.
\end{enumerate}
In each step, all parameters not being updated are held at their most recently sampled values. These steps are repeated many times. Early draws depend strongly on the starting values, so the first part of the chain is discarded as burn-in. The remaining draws approximate the joint posterior. Figure~\ref{fig:gibbs_diagram} summarises the three-step Gibbs iteration graphically.

\paragraph{Step 1: Sampling the hidden state path via FFBS.}

The full latent regime sequence $(s_1,\dots,s_T)$ is sampled conditional on the current parameters using Forward-Filtering Backward-Sampling (FFBS).

The forward pass computes the filtered probability $\alpha_t(k) = P(s_t=k \mid \mathbf{z}_{1:t})$ via the recursion
\begin{equation}
\alpha_t(k)
=
\frac{f(\mathbf{z}_t \mid s_t=k)\;\displaystyle\sum_{j=0}^{1} \alpha_{t-1}(j)\,P_{jk}}
     {\displaystyle\sum_{k'=0}^{1} f(\mathbf{z}_t \mid s_t=k')\;\sum_{j=0}^{1} \alpha_{t-1}(j)\,P_{jk'}},
\label{eq:forward_plain}
\end{equation}
where $f(\mathbf{z}_t \mid s_t=k) = \mathcal{N}(\mathbf{z}_t;\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k)$ is the Gaussian emission density. The recursion is initialized with $\alpha_0(k) = 1/2$. The filtered probability at each month reflects both how well the current features fit each regime and how likely each regime was given the previous month's classification.

The backward pass then samples a coherent state path in reverse order: $s_T \sim \text{Cat}(\alpha_T(0),\alpha_T(1))$, where $\text{Cat}$ denotes the categorical distribution (a single draw from a discrete probability vector), and for $t=T-1,\dots,1$,
\begin{equation}
s_t \sim \text{Cat}\!\left(
\frac{\alpha_t(k)\,P_{k,s_{t+1}}}
{\sum_{j=0}^{1}\alpha_t(j)\,P_{j,s_{t+1}}}
\right),
\label{eq:backward_sampling}
\end{equation}
ensuring that the sampled path respects the Markov transition dynamics. Importantly, this backward sampling step is performed only during model \emph{training} (the Gibbs sampler on 1990--2010 data). It is not used to construct the trading signal: the real-time filtered probability $\pi_t^{\text{filter}}$ used for portfolio construction relies solely on the causal forward filter, which conditions only on past and current observations $\mathbf{z}_{1:t}$. The backward pass serves to improve the quality of posterior parameter estimates by providing the Gibbs sampler with more accurate state assignments, but it does not introduce any future information into the regime signal applied during the test period. The output is one draw from the posterior over state paths; across Gibbs iterations, different paths are sampled, exploring the full posterior uncertainty. A detailed derivation of the FFBS recursion and a flowchart of the algorithm are provided in Appendix~\ref{app:ffbs}.

\paragraph{Step 2: Updating the emission parameters.}

Conditional on the sampled state path, the $n_k$ observations assigned to regime $k$ yield sufficient statistics: the sample mean $\bar{\mathbf{x}}_k = \frac{1}{n_k}\sum_{t:\,s_t=k}\mathbf{z}_t$ and the scatter matrix $\mathbf{S}_k = \sum_{t:\,s_t=k}(\mathbf{z}_t - \bar{\mathbf{x}}_k)(\mathbf{z}_t - \bar{\mathbf{x}}_k)^\top$. The Normal-Inverse-Wishart prior updates to a posterior with hyperparameters
\begin{equation}
\kappa_n = \kappa_0 + n_k,
\quad
\mathbf{m}_n = \frac{\kappa_0 \mathbf{m}_0 + n_k \bar{\mathbf{x}}_k}{\kappa_n},
\quad
\nu_n = \nu_0 + n_k,
\quad
\boldsymbol{\Psi}_n
=
\boldsymbol{\Psi}_0
+
\mathbf{S}_k
+
\frac{\kappa_0 n_k}{\kappa_n}
(\bar{\mathbf{x}}_k-\mathbf{m}_0)(\bar{\mathbf{x}}_k-\mathbf{m}_0)^\top,
\label{eq:niw_update}
\end{equation}
from which new regime parameters are drawn:
$\boldsymbol{\Sigma}_k \sim \mathcal{IW}(\nu_n,\boldsymbol{\Psi}_n)$ and
$\boldsymbol{\mu}_k \mid \boldsymbol{\Sigma}_k \sim \mathcal{N}(\mathbf{m}_n, \boldsymbol{\Sigma}_k / \kappa_n)$.
Since $\kappa_0=0.01$, the posterior means are driven almost entirely by the data.

\paragraph{Step 3: Updating the transition matrix.}

The transition counts $n_{ij} = \sum_{t=2}^T \mathbb{1}(s_{t-1}=i, s_t=j)$ are combined with the Dirichlet prior:
\begin{equation}
\mathbf{P}_{i,\cdot} \mid \{s_t\}
\sim
\text{Dir}\!\big(\boldsymbol{\alpha}_i + \mathbf{n}_i\big),
\label{eq:dirichlet_update}
\end{equation}
where $\boldsymbol{\alpha}_i$ is the prior pseudo-count vector for row $i$. When the sampled path stays in one regime for long stretches, the posterior concentrates around high persistence.

\paragraph{Implementation Details.}\label{sec:implementation}

The Gibbs sampler is estimated on the training sample only (1990--2010). To reduce sensitivity to MCMC initialization, the full sampler is run independently with $N_s = 5$ different random seeds. Each chain is run for $M=2{,}000$ iterations with the initialization described above. The first $B=500$ iterations are discarded as burn-in, leaving $1{,}500$ posterior draws per seed.

For each seed, posterior mean parameters $\bar{\boldsymbol{\mu}}_k$, $\bar{\boldsymbol{\Sigma}}_k$, and $\bar{\mathbf{P}}$ are computed by averaging over the post-burn-in draws. A causal forward filter is then applied to the full sample using these parameters to obtain a seed-specific filtered probability $\pi_t^{\text{filter},(s)}$. The final trading signal is the average across seeds:
\begin{equation}
\pi_t^{\text{filter}} = \frac{1}{N_s} \sum_{s=1}^{N_s} \pi_t^{\text{filter},(s)}.
\end{equation}
This Bayesian model averaging reduces the variance of the regime signal and produces more stable downstream portfolio performance. No test-period data is used in estimation.

\paragraph{Convergence Diagnostics.}\label{sec:convergence}

Convergence is assessed in two ways. First, trace plots of the regime means and persistence probabilities are visually inspected to verify that the chain mixes around a stable posterior region after burn-in. Second, effective sample sizes (ESS) are computed for key parameters. Because successive MCMC draws are autocorrelated, $n$ draws from the chain contain less information than $n$ independent samples. The ESS quantifies the number of truly independent draws the chain is equivalent to. For a post-burn-in chain of length $n$,
\begin{equation}
ESS
=
\frac{n}{1 + 2\sum_{\ell=1}^{L^\ast}\hat{\rho}(\ell)},
\end{equation}
where $\hat{\rho}(\ell)$ is the estimated autocorrelation at lag $\ell$, and $L^\ast$ is the first lag at which the autocorrelation becomes negative. High ESS indicates that the chain provides many effectively independent posterior draws.

Figure~\ref{fig:convergence_trace} displays the trace plots for the regime means of all four features and the persistence probabilities $P_{00}$ and $P_{11}$ across $2{,}000$ Gibbs iterations. The dashed vertical line marks the end of the burn-in period at iteration $500$. After burn-in, the chains fluctuate around stable values, indicating that the sampler has converged to the posterior distribution.

\subsubsection{Regime Identification and Trading Signal}\label{sec:regime_signal}

\paragraph{Label Switching and Regime Naming.}\label{sec:label_switching}

In a two-state HMM, the labels $0$ and $1$ are intrinsically arbitrary: relabeling the states leaves the likelihood unchanged. To attach an economically meaningful interpretation to the states, a \emph{crisis-calibrated sign correction} procedure is applied.

Because the four HMM features respond to stress in different directions (VOL and DISP rise during crises, while DD and REL\_N fall), a single feature cannot reliably identify the panic state. Instead, the expected direction of each feature during stress is determined empirically. For each feature $j$, the 95th percentile is computed separately on training months falling within known crisis windows (the dot-com bust of 2000--2002 and the Global Financial Crisis of 2007--2009) and on all remaining training months:
\begin{equation}
\text{sign}_j =
\begin{cases}
+1 & \text{if } q_{0.95}^{\text{crisis}}(z_j) \geq q_{0.95}^{\text{normal}}(z_j), \\
-1 & \text{otherwise}.
\end{cases}
\end{equation}
Features that spike upward during crises receive $\text{sign}_j = +1$; features that decline receive $\text{sign}_j = -1$. The panic state is then identified as the regime $k \in \{0, 1\}$ whose posterior mean vector $\hat{\boldsymbol{\mu}}_k$ best aligns with the crisis direction:
\begin{equation}
k^\ast = \arg\max_{k \in \{0,1\}} \sum_{j=1}^{D} \text{sign}_j \cdot \hat{\mu}_{k,j}.
\end{equation}
The state labelled $k^\ast$ is designated as ``panic'' and the other as ``calm.'' If the Gibbs sampler happens to assign the panic characteristics to state~0 rather than state~1, the labels are swapped so that $\pi_t^{\text{filter}}$ always represents the probability of the panic state. This procedure is robust to the heterogeneous directional responses of the four features and yields consistent panic identification across all random seeds used in estimation.

\paragraph{Filtered Regime Probability.}\label{sec:trading_signal}

The output of the HMM estimation is a time series of filtered regime probabilities. Using the posterior mean parameters $\bar{\boldsymbol{\mu}}_k$, $\bar{\boldsymbol{\Sigma}}_k$, and $\bar{\mathbf{P}}$ (estimated on the training sample only), the forward recursion from Equation~(\ref{eq:forward_plain}) is applied to the full sample to obtain, for each month $t$,
\begin{equation}
\pi_t^{\text{filter}}
=
P(s_t=\text{panic} \mid \mathbf{z}_{1:t};\,\bar{\boldsymbol{\mu}},\bar{\boldsymbol{\Sigma}},\bar{\mathbf{P}}).
\end{equation}
This quantity represents the probability that the market is in the panic regime at month $t$, conditional on all observed features up to and including $t$. It is strictly causal (no future information is used) and is computed for both the training and test periods. A value near $0$ indicates high confidence in the calm regime, a value near $1$ indicates high confidence in panic, and intermediate values reflect genuine ambiguity between the two states. This filtered probability serves as the regime signal passed to the portfolio construction methods described in Section~\ref{sec:methods}.

\subsection{Stage 2: Regime-Conditioned Portfolio Construction}\label{sec:stage2}

The filtered regime probability $\pi_t^{\text{filter}}$ from Stage~1 provides a monthly measure of market stress, but on its own it does not select stocks. This stage translates the regime signal into cross-sectional portfolios. Three scoring methods of increasing complexity are developed: a deterministic regime-adaptive momentum formula (Method~0), a logistic regression classifier (Method~1), and an XGBoost gradient-boosted tree regressor (Method~2). Each method combines $\pi_t^{\text{filter}}$ with a set of momentum and fundamental stock characteristics to produce a monthly score for every stock, which is then used to rank stocks into a long-only top-decile value-weighted portfolio.

The deterministic formula serves as a transparent baseline that tests whether simply varying the momentum lookback horizon with market conditions adds value. The two machine learning methods go further by jointly learning how all features (momentum at multiple horizons, fundamentals, and the regime signal) interact to predict forward returns. The results that follow (Section~\ref{sec:results}) not only compare the out-of-sample performance of the three portfolios but also use SHAP values and coefficient analysis to examine \emph{which} features drive the predictions and \emph{how} their importance shifts across calm and panic regimes. This feature-level analysis provides economic insight into the signals that distinguish regime-conditioned stock selection from standard momentum.

\subsubsection{Scoring Methods}\label{sec:methods}

All three methods are trained on the pre-2011 sample and evaluated out-of-sample on 2011--2025.

\paragraph{Method 0: Deterministic Regime-Adaptive Formula.}\label{sec:method0}

The simplest approach exploits the economic intuition that the optimal momentum lookback horizon varies with market conditions. The lookback horizon is determined by:
\begin{equation}
    \ell_t = \text{clip}\!\left(\text{round}(12 - 11 \cdot \pi_t^{\text{filter}}), \; 1, \; 12\right),
\end{equation}
and each stock's score is simply its momentum return at the selected horizon:
\begin{equation}
    score_t^s = mom_{\ell_t, t}^s.
\end{equation}
Stocks are then ranked by this score, and the top decile forms the long portfolio as described in Appendix~\ref{app:portfolio_construction}.

When $\pi_t^{\text{filter}} \approx 0$ (calm), $\ell_t = 12$, recovering the standard 12-month momentum signal that captures continuation in trending markets. When $\pi_t^{\text{filter}} \approx 1$ (panic), $\ell_t = 1$, switching to 1-month reversal to exploit the tendency of oversold stocks to snap back after panic selling. At intermediate values, the lookback smoothly interpolates between these extremes.

\paragraph{Method 1: Logistic Regression.}\label{sec:method1}

A logistic regression classifier is trained to predict whether a stock's forward return exceeds the cross-sectional median in each month:
\begin{equation}
    P(y_t^s = 1 \mid \mathbf{x}_t^s) = \sigma(\boldsymbol{\beta}^\top \tilde{\mathbf{x}}_t^s),
\end{equation}
where $\sigma(z) = 1/(1 + e^{-z})$ is the logistic sigmoid function and $y_t^s = \mathbb{1}(r_{t+1}^s > \text{median}_s\{r_{t+1}^s\})$ is a binary label indicating whether stock $s$ outperforms the cross-sectional median in the following month. The feature vector $\tilde{\mathbf{x}}_t^s$ is standardized using training-set means and standard deviations, with missing fundamental values imputed at the training-set median. The model is estimated by maximizing the $\ell_2$-regularized log-likelihood:
\begin{equation}
    \hat{\boldsymbol{\beta}} = \arg\max_{\boldsymbol{\beta}} \left[\sum_{i} \Big(y_i \log \sigma(\boldsymbol{\beta}^\top \tilde{\mathbf{x}}_i) + (1 - y_i) \log(1 - \sigma(\boldsymbol{\beta}^\top \tilde{\mathbf{x}}_i))\Big) - \frac{1}{2C} \|\boldsymbol{\beta}\|_2^2\right],
\end{equation}
with regularization strength $C = 1.0$. Once $\hat{\boldsymbol{\beta}}$ is estimated on the training sample, the stock score for any observation is obtained by plugging $\hat{\boldsymbol{\beta}}$ back into the prediction equation:
\begin{equation}
    score_t^s = \sigma(\hat{\boldsymbol{\beta}}^\top \tilde{\mathbf{x}}_t^s) = P(y_t^s = 1 \mid \mathbf{x}_t^s;\, \hat{\boldsymbol{\beta}}).
\end{equation}
Stocks with higher predicted probability of beating the cross-sectional median receive higher scores and are more likely to enter the top-decile portfolio.

\paragraph{Method 2: XGBoost Regressor.}\label{sec:method2}

An XGBoost gradient-boosted tree regressor \citep{Chen2016} is trained to predict the forward monthly return directly. The feature vector for each stock-month observation comprises the same 20 features described in Section~\ref{sec:cs_features}: the 12 momentum lookbacks ($mom_1, \dots, mom_{12}$), the regime signal ($\pi_t^{\text{filter}}$), and the 7 fundamental characteristics. By including all features jointly, XGBoost can learn which momentum horizons and fundamentals matter most in each regime. For example, it may rely on long-horizon momentum when $\pi_t^{\text{filter}}$ is low but shift toward short-term reversal and defensive fundamentals when $\pi_t^{\text{filter}}$ is high.

XGBoost builds an additive ensemble of $M$ regression trees, where each successive tree fits the residuals of the current ensemble:
\begin{equation}
    F(\mathbf{x}) = \sum_{m=1}^{M} \eta \cdot h_m(\mathbf{x}),
\end{equation}
where $h_m$ is the $m$-th decision tree and $\eta$ is the learning rate that shrinks each tree's contribution to prevent overfitting. Each tree $h_m$ is grown to minimize a regularized objective combining the squared-error loss on the current residuals with penalty terms on tree complexity (number of leaves and leaf weights). The predicted return $\hat{r}_{t+1}^s = F(\mathbf{x}_t^s)$ serves as the stock score. Key hyperparameters are listed in Table~\ref{tab:xgb_params}.

Row and column subsampling introduce stochasticity into each boosting round, reducing variance and improving generalization. A maximum depth of 4 allows the model to capture pairwise and higher-order interactions. Critically, this means XGBoost can learn splits that condition on $\pi_t^{\text{filter}}$ and then branch on momentum horizons differently within each regime, without requiring explicit interaction terms. XGBoost also natively handles missing values in the fundamental features by learning optimal split directions for missing entries during training, eliminating the need for imputation.

\paragraph{The Role of $\pi_t^{\text{filter}}$.}\label{sec:pi_context}

A key distinction between Methods~1 and~2 lies in how each model uses the regime signal. Logistic regression assigns $\pi_t^{\text{filter}}$ a single linear coefficient, which is near zero because the regime signal is not a direct return predictor. XGBoost, by contrast, uses $\pi_t^{\text{filter}}$ as a \emph{context variable} through tree splits, conditioning its use of momentum horizons on the current market state. This interaction effect cannot be represented by a single linear coefficient. The empirical consequences of this distinction are analysed in Section~\ref{sec:context_results}.
